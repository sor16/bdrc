# Custom bdrc theme

Custom bdrc theme

## Usage

``` r
theme_bdrc(scaling = 1, ...)
```

## Arguments

- scaling:

  a numerical value which can be used to scale up or down the size of
  the text and titles of a plot that uses `theme_bdrc`. Defaults to 1.

- ...:

  not used in this function

## Value

returns a theme object for the package
