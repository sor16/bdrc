# Print method for discharge rating curve tournament

Print the results of a tournament of discharge rating curve model
comparisons

## Usage

``` r
# S3 method for class 'tournament'
print(x, ...)
```

## Arguments

- x:

  An object of class "tournament"

- ...:

  Not used in this function
